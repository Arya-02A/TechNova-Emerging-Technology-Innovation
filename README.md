# 🚀 TechNova | Emerging Technology & Innovation

A sleek, multi-page website dedicated to showcasing the cutting edge of futuristic **Emerging Technologies**, **Groundbreaking Research**, and our **Future Vision**. Built with a focus on modern design, intuitive UI/UX, and a seamless Dark/Light theme experience.

---

## 🏆 Competition 1st Prize Award Winner 🏆

**TechNova was the winning project at the Intercollege Vibe Coding Competition held at MM Polytechnic, Pune!**

The project was specially recognized by the judges for its:

* **Stunning UI/UX:** A highly polished, futuristic design that successfully captured the "vibe" of next-generation technology.
* **Innovative Theming:** The seamless and immediate Dark/Light Mode toggle, achieved purely with CSS.
* **Clean Codebase:** Demonstrating mastery over foundational web technologies (HTML/CSS) to create a complex, multi-page experience.

---

## ✨ Key Features

* **🌌 Futuristic, Responsive Design:** A clean, dark-mode-first aesthetic with modern typography, subtle animations, and gradient accents for a high-tech feel.
* **🌓 Seamless Theme Toggle:** Instantaneous switch between Dark and Light themes for optimal viewing comfort, managed entirely via a CSS toggle mechanism.
* **📱 Fully Responsive:** Perfect presentation on all devices, from mobile phones to large desktop monitors.
* **🧠 Comprehensive Content Modules:** Dedicated pages to explore key areas like **Artificial Intelligence**, **Quantum Computing**, **Biotechnology**, **Space Exploration**, and **Future Vision Timelines** (2030, 2040, etc.).
* **👤 Team Showcase:** A clean section to introduce the visionary minds behind the project.

---

## 🛠️ Tech Stack

This project demonstrates strong front-end capability using only foundational technologies:

* **HTML5:** Semantic structure for all multi-page layouts (`index.html`, `technologies.html`, `research.html`, etc.).
* **CSS3:** Custom styling for all layouts, theming, and animations.
    * Utilizes **Flexbox** and **CSS Grid** for complex, responsive layouts.
    * Leverages **CSS variables** for easy, maintainable theme switching.
